# 未踏之地（Demo）

> 一个以学习为目的制作的 2D 横版像素风类银（Metroidvania）游戏 Demo。

## 项目简介

《未踏之地》是一款用于学习与实践的 2D 横版像素风 Demo，采用类银河恶魔城式的设计思路。项目涵盖场景关卡、战斗动作、角色养成与配套系统，力求完整走通一款横版动作游戏的开发流程。

## 演示视频-B站

 https://www.bilibili.com/video/BV1NtTt6VEXs/

## 游戏内容

- **场景关卡**：包含多个风格各异的场景与关卡，并配置了多种怪物。
- **动作战斗**：玩家可施展多样的动作与连招，支持自由的技能搭配。
- **成长系统**：提供背包、仓库、合成、属性表与加点、技能等玩法系统。

## 配套功能

- 较为完整的 UI 界面
- 存档系统
- 背景音乐与音效
