## 技术要点

### 架构与工程

- **配置驱动**：角色属性、技能、道具、怪物参数外置为 ScriptableObject 资产，新增内容只加配置、不改代码
- **状态机**：玩家与敌人共用一套 FSM 模板，状态各自独立成类，新增动作只需注册新状态，不修改既有状态
- **对象池**：敌人、伤害飘字、特效由对象池统一管理，避免高频 `Instantiate` 造成的 GC 抖动
- **数据持久化**：JSON 序列化存档，支持多存档位
- **Editor 扩展**：自定义编辑器工具，用于批量校验配置资产、快速生成内容
- **输入系统**：基于 Input System 的统一输入层，便于键位重绑定

### 玩法系统

| 系统       | 内容                          |
| -------- | --------------------------- |
| 动作战斗     | 多段连招、位移取消、受击反馈、格挡判定         |
| 技能树      | 分支式技能解锁、前置依赖校验、节点状态持久化      |
| 背包 / 仓储  | 格子式背包、仓库转移、堆叠与分类            |
| 装备与属性    | 属性表、加点、装备加成叠加计算             |
| 商店与合成    | 货币结算、配方合成、购买校验              |
| Buff 系统  | 时效性 Buff 的挂载、叠加、驱散与表现同步     |
| 敌人 AI    | 多种行为模式的敌人，巡逻 / 追击 / 攻击状态切换  |
| 机关与陷阱    | 可交互机关、门禁、平台与场景联动            |
| 存档       | 进度、背包、技能树、场景状态的完整序列化        |

### 表现

- Tilemap + 视差背景搭建关卡，Tilesetter 制作瓦块
- 动画控制器驱动角色动作，配合音效与 BGM
- 受击反馈、传送门等视觉效果以材质参数驱动

## 如何运行

**方式一：在线试玩（最快）**

直接打开 <https://ht-plxl.github.io/Metroidvania-Unrecorded_World-Demo/>

**方式二：下载 Windows 版**

到 [Releases](../../releases) 下载压缩包，解压后双击 exe 即可，无需安装。

**方式三：从源码运行**

1. Unity **6000.0.38f1**（Unity 6）打开仓库根目录，首次导入约 3–5 分钟
2. 打开 `Assets/Scenes/正式场景/主菜单`
3. 点击 Play
